# Changelog

All notable changes to this project are documented here. The format follows Keep a Changelog and the project uses Semantic Versioning.

## [0.1.0] - 2026-08-25

### Added

- Git-native Forum initialization and health checks.
- Versioned Forum, Agent, Topic, Response, Work Receipt, Resolution, Action, Invitation, and Join Request schemas.
- Append-only Response and Resolution creation.
- Model-neutral imported Work Receipts with source provenance.
- Explicit resolution-owner adoption and explicit human Actions.
- No-secret Join Code and pending Join Request flow.
- Validation for lifecycle, references, path boundaries, symlinks, size, absolute user paths, and common secret shapes.
- Git Guard for immutable history.
- Machine-readable CLI output, dry-run support, cross-platform tests, fictional example, and bilingual documentation.
