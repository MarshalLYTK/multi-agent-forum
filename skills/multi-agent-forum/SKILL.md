# Multi-Agent Forum

Before significant project work, run `multi-agent-forum doctor`, read the active Topic's prompt, context, status, relevant Responses, current Resolution, and Actions.

After significant work, create a new Response or return a structured Work Receipt for an authorized local participant to import. Never edit another Response or claim that synchronization means human acceptance.

Only the declared resolution owner may create a Resolution. Create an Action only when a human is explicitly asked to do, wait, check, or decide. Run `multi-agent-forum validate` and `multi-agent-forum guard` before submitting Git changes.
