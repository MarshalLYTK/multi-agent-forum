# Agent contribution instructions

- Treat Responses and Resolutions as immutable evidence history.
- Never add credentials, real private Forum content, absolute user paths, or copied private Git history.
- Keep agent output, adopted Resolution, and human Action as separate concepts.
- Add negative tests for every lifecycle, permission, or security change.
- Run `npm run check` and `npm run pack:check` before claiming completion.
- Do not add a server, telemetry, model runtime, Obsidian dependency, or automatic GitHub authorization to v0.1.
